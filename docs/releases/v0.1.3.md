# InkLeaf v0.1.3

## Highlights

- Stabilized Reader and Split layouts — removed double-border visual regression
- Flat Reader paper design for a cleaner reading experience
- Removed unstable Source ↔ Reader selection mapping (redesigned in future release with AST source map)
- Improved Source and Reader selection colors to solid deep blue
- Fixed recent file cleanup — automatically removes missing files on startup
- Improved drag-and-drop: images copy to assets, non-images insert Markdown links
- Fixed drop ordering for multiple files
- Unified image and file path encoding for special characters
- Fixed outline navigation — uses github-slugger for reliable heading matching
- Added Markdown formatting toolbar in Source mode
- Added startup update check via GitHub Releases
- Added first-run default app prompt
- Hardened external link and local image protocol handling
- Cleaned up release metadata and documentation

## Download

- InkLeaf Setup 0.1.3.exe — Windows installer

## Notes

- Source ↔ Reader synchronized selection mapping is intentionally disabled in v0.1.3 and will be redesigned with Markdown AST source mapping in a future release.
- Files larger than 100 MB are not currently supported.
