# InkLeaf v0.1.4

## Highlights

- Existing files now open directly in Reader mode.
- Source and Split editors are loaded only when requested, keeping the reading startup path smaller.
- Optional startup session restore reopens file-backed tabs and the active tab without storing document contents.
- Added Focused, Comfortable, and Wide one-click reading presets.
- Added `Ctrl+Tab` and `Ctrl+Shift+Tab` tab cycling.
- Simplified the welcome screen around the primary Open File action.

## Reliability and security

- Fixed the Default Opener action so it uses the dedicated Windows settings bridge.
- Fixed startup argument handling so opening a file directly takes precedence over session restore without duplicate tabs.
- Fixed unhandled `ERR_FILE_NOT_FOUND` errors when a local image is missing; the asset protocol now returns a clean 404 response.
- Updated DOMPurify to 3.4.14 and removed its obsolete external type stub.
- Switched packaging and development icons to the maintained Electron icon source.
- Production dependency audit reports no known vulnerabilities.

## Notes

- Session restore stores at most 20 local file paths and the active path. Unsaved contents remain protected by the separate recovery-draft flow.
- Files larger than 100 MB are not currently supported.
- Source ↔ Reader synchronized selection mapping remains intentionally disabled until it can be rebuilt on a reliable Markdown AST source map.

## 更新亮点

- 已有文件现在直接进入阅读模式。
- 源码与分屏编辑器改为按需加载，减少纯阅读启动路径。
- 新增可关闭的启动会话恢复：恢复文件标签和当前标签，不保存文档正文。
- 新增窄幅、舒适、宽屏三种一键阅读预设。
- 新增 `Ctrl+Tab` 与 `Ctrl+Shift+Tab` 标签切换。
- 欢迎页突出“打开文件”，首次使用更直接。

## 稳定性与安全

- 修复“设为默认打开器”无法正确进入 Windows 默认应用设置的问题。
- 修复启动参数处理，双击文件时会优先打开目标文件，且不会与会话恢复产生重复标签。
- 修复本地图片不存在时主进程出现未处理 `ERR_FILE_NOT_FOUND` 的问题，现统一返回 404 并由界面友好降级。
- DOMPurify 升级至 3.4.14，并移除已废弃的外部类型包。
- 开发和打包统一使用受维护的 Electron 图标资源。
- 生产依赖审计无已知漏洞。
